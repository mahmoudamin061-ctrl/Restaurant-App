10 BUG FIXES SUMMARY
================================================================

BUG 1  RunSimulation() loop order
       FinishInServiceOrders() now runs FIRST so freed tables/scooters
       are available when AssignReadyOrders() runs in the same step.

BUG 2  SaveToFile() output always empty
       Sort loop no longer re-enqueues maxOrd back into FINISHED.
       Each pass correctly finds, writes, and discards the max.

BUG 3  OT packing takes 0 timesteps
       Check changed from else to currentTimeStep > ord->getTS()
       guaranteeing exactly 1 full step of packing time.

BUG 4  Cancel searches in-service list (not allowed)
       In-service block removed from RemoveOrderOVC(). Spec says
       only pending, cooking, and ready OVC orders can be cancelled.

BUG 5  Shared table resets all seats when any order leaves
       Table::releaseSeats(int) added. InServiceEntry stores seatsUsed.
       Only the leaving order's seats are restored.

BUG 6  Scooter stats counted too early, return trip missing
       recordDelivery() and addDistance() moved from AssignDeliveryBatch()
       to FinishInServiceOrders(). Both trip directions counted.

BUG 7  Debug cout in production
       8-line [DBG] block deleted from FinishInServiceOrders().

BUG 8  PrintActions shows only timestamp
       Virtual print() added to Action. Subclasses override it.
       PrintActions calls first10[i]->print() for correct format.

BUG 9  AccumulateStats() declared but never defined
       Dead declaration removed from Restaurant.h.

BUG 10 Overwait % always 0
       totalOverwaitCount counter added, incremented in CheckOverwait(),
       used in SaveToFile() instead of reading the (empty) queue.
